# 📜 许可速查


## 可以卖（原样打包）

- **CC0 1.0 / Public Domain** —— 放弃全部权利，最自由。署名都不需要。
- **CC-BY** —— 可商用、可再分发，**必须署名**。
- **MIT / Apache 2.0 / BSD** —— 软件许可，可商用，保留版权声明即可。
- **OFL** —— 字体许可，可商用、可嵌入、可再分发。

## 可以卖，但有传染

- **CC-BY-SA** —— 署名 + 你的衍生作品必须也用 CC-BY-SA。
- **GPL / LGPL** —— 分发时必须提供源码。
- **ODbL** —— 数据库许可，衍生库须同许可。

## 不能卖

- **CC-BY-NC** —— 禁止任何商业使用。**MIT OCW、可汗学院、多数 MOOC 都在此列。**
- **Unsplash / Pexels / Pixabay License** —— 明确禁止「原样转卖」和「做成竞品图库」；只能作为素材用于你自己的作品。
- **保留所有权利 / 平台服务条款** —— 免费观看不等于授权再分发。

## 常见误区

| 误区 | 事实 |
|---|---|
| 「网上能免费下载 = 可以卖」 | ❌ 免费访问 ≠ 分发授权 |
| 「免费教育网站 = 可以打包卖」 | ❌ MIT OCW 等是 NC，禁止商业 |
| 「Unsplash 免费 = 可以做人肉图库卖」 | ❌ 其许可明文禁止原样转卖 |
| 「arXiv 论文都能用」 | ❌ 多数是 arXiv 专属许可，禁止再分发 |
| 「公开发布的就能用」 | ❌ 个人信息还受《个人信息保护法》约束 |
